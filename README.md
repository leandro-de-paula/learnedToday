# Learned Today

Repositório pessoal de **Leandro de Paula** dedicado ao registro de aprendizado e evolução profissional no desenvolvimento de software. A ideia central é documentar a jornada de estudos diários, um dia de cada vez, construindo uma base sólida de conhecimentos, desde o uso de tecnologias "vanilla" até bibliotecas e frameworks.

> "Lembre-se, até a mais alta torre começou de baixo."

## Estrutura do Repositório

- **[frontEnd](./frontEnd/)**: Contém projetos, estudos de HTML, CSS (layouts fixos, fluidos, menus), JavaScript puro e bibliotecas como jQuery.
- **[backEnd](./backEnd/)**: Focado nos estudos de lógica de servidor e desenvolvimento de APIs, atualmente explorando Node.js.
